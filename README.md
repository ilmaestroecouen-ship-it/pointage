# Il Maestro — Pointage du personnel

Application de pointage pour tablette (iPad) : les salariés tapent leur code et pointent leur arrivée / fin de service ; le gérant suit les heures par jour, semaine et mois et exporte un fichier Excel pour la paie.

- **Site** : `index.html` (GitHub Pages)
- **Données** : Google Sheet via Google Apps Script (`google-apps-script/`)
- **Réglage** : l'URL du programme Google se colle dans `config.js` (vide = mode démo)

👉 Installation et utilisation : voir [GUIDE-INSTALLATION.md](GUIDE-INSTALLATION.md)
